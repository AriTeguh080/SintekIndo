SINTEKINDO WEBSITE - HTML/CSS/JS

File utama:
- index.html : Home
- projects.html : Portofolio 16 project
- projects/*.html : detail masing-masing project
- team.html : Tim
- events.html : Event
- blog-seo.html dan blog-security.html : artikel
- styles.css : seluruh styling responsif
- script.js : menu mobile, popup teknologi, pencarian project, form mailto
- assets/ : logo, foto tim, gambar project, dan gambar pendukung

Cara menjalankan:
1. Extract ZIP.
2. Buka index.html langsung di browser, atau gunakan Live Server di VS Code.
3. Untuk deployment, upload seluruh isi folder tanpa mengubah struktur.

Breakpoint utama:
- Desktop/PC > 1100px
- Laptop/Tablet landscape <= 1100px
- Tablet/mobile <= 900px
- Mobile <= 600px
